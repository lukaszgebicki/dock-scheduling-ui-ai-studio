# Dock Scheduling UI — AI Studio Sandbox

To repozytorium służy wyłącznie do projektowania i eksperymentowania z interfejsem użytkownika w Google AI Studio. Nie zawiera backendu produkcyjnego, bazy danych ani infrastruktury wdrożeniowej.

Repozytorium produkcyjne: `lukaszgebicki/dock-scheduling-app-ai-studio1707`

Commit źródłowy: `c758e8403a4693fa7ba96081254072ad5d743aba`

Repozytorium produkcyjne na GitHubie pozostaje jedynym źródłem prawdy. Zmian z tego sandboxa nie wolno kopiować automatycznie do produkcji — każda zmiana wymaga przeglądu.

## Uruchomienie i weryfikacja

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```
